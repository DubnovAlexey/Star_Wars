# Star Wars (HTML и CSS)

[English](README.md) · [עברית](README.he.md) · **Русский**

Моя первая страница о «Звёздных войнах» на HTML и CSS, ещё до версии на React ([star-wars-ts-routing](https://github.com/DubnovAlexey/star-wars-ts-routing)). На ней вступительные титры «Новой надежды», фото героя и галерея друзей, свёрстанные тремя способами: таблицей, Flexbox и центрированным Flexbox.

**Демо:** https://dubnovalexey.github.io/Star_Wars/

## Что внутри

- `src/index.html` — главная страница; `src/index_flex.html` и `src/centerFlex.html` — то же содержание на Flexbox.
- Звёздный фон и оформление в стиле «Звёздных войн» на чистом CSS.
- `starsWars.txt` — исходный текст титров.

## Стек

HTML5 · CSS3 (Flexbox) · GitHub Pages

## Ветки

- `main` — опубликованная версия.
- `boodStrap` — более новая работа: переделанная, более адаптивная страница. Её ещё нужно влить в `main`.

## Как запустить

Откройте `index.html` (или `src/index.html`) в браузере.

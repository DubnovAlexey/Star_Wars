# Star Wars (HTML & CSS)

**English** · [עברית](README.he.md) · [Русский](README.ru.md)

My first Star Wars fan page, made with HTML and CSS before the React version ([star-wars-ts-routing](https://github.com/DubnovAlexey/star-wars-ts-routing)): the opening crawl of *A New Hope*, a hero photo and a gallery of friends, laid out three ways — a table, Flexbox and a centred Flexbox variant.

**Live demo:** https://dubnovalexey.github.io/Star_Wars/

## What is inside

- `src/index.html` — the main page; `src/index_flex.html` and `src/centerFlex.html` — the same content with Flexbox layouts.
- A starry background and Star Wars styling in plain CSS.
- `starsWars.txt` — the source text of the opening crawl.

## Tech stack

HTML5 · CSS3 (Flexbox) · GitHub Pages

## Branches

- `main` — the published version.
- `boodStrap` — newer work: a refactored page with a more responsive layout. It still has to be merged into `main`.

## Run locally

Open `index.html` (or `src/index.html`) in a browser.

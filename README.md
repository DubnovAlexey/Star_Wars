## English

A static Star Wars layout study in HTML and CSS, preceding the React version ([star-wars-ts-routing](https://github.com/DubnovAlexey/star-wars-ts-routing)): the opening crawl of *A New Hope*, a hero photo and a gallery of friends, laid out three ways — a table, Flexbox and a centred Flexbox variant.

**Live demo:** https://dubnovalexey.github.io/Star_Wars/

### Try it

Open src/index.html, src/index_flex.html and src/centerFlex.html to compare the same composition in three layouts. Resize the window and inspect the hero image and dream-team gallery.

### What is inside

- `src/index.html` — the main page; `src/index_flex.html` and `src/centerFlex.html` — the same content with Flexbox layouts.
- A starry background and Star Wars styling in plain CSS.
- `starsWars.txt` — the source text of the opening crawl.

### Tech stack

HTML5 · CSS3 (Flexbox) · GitHub Pages

### Run locally

Open `index.html` (or `src/index.html`) in a browser.

### Demo scope

This is a static layout study. The navigation labels and “Send me email” are decorative placeholders; there is no API, message sending or interactive hero routing.

### Further development

Proposals below are planned work, not existing features.

- Visual: align spacing and mobile typography across the three layouts, with a shared small Star Wars favicon.
- Engineering: give the navigation real links and visible keyboard focus; consolidate repeated style rules while preserving the layout examples.
- Features: add a layout comparison switch and an accessible enlarged view of the gallery.

## Русский

**Star Wars (HTML и CSS)**

Статическое исследование вёрстки о «Звёздных войнах» на HTML и CSS, предшествующее версии на React ([star-wars-ts-routing](https://github.com/DubnovAlexey/star-wars-ts-routing)). На ней вступительные титры «Новой надежды», фото героя и галерея друзей, свёрстанные тремя способами: таблицей, Flexbox и центрированным Flexbox.

**Демо:** https://dubnovalexey.github.io/Star_Wars/

### Попробовать

Откройте src/index.html, src/index_flex.html и src/centerFlex.html: это одна композиция в трёх вариантах вёрстки. Измените ширину окна и сравните портрет героя с галереей команды.

### Что внутри

- `src/index.html` — главная страница; `src/index_flex.html` и `src/centerFlex.html` — то же содержание на Flexbox.
- Звёздный фон и оформление в стиле «Звёздных войн» на чистом CSS.
- `starsWars.txt` — исходный текст титров.

### Стек

HTML5 · CSS3 (Flexbox) · GitHub Pages

### Как запустить

Откройте `index.html` (или `src/index.html`) в браузере.

### Границы демонстрации

Это статическое исследование вёрстки. Названия меню и «Send me email» декоративные: загрузки API, отправки сообщений и интерактивных маршрутов героев здесь нет.

### Дальнейшее развитие

Ниже перечислены предложения, а не уже реализованные функции.

- Визуал: согласовать отступы и мобильную типографику трёх вариантов; общий малый favicon Star Wars.
- Инженерия: настоящие ссылки навигации и заметный фокус с клавиатуры; вынести общие стили, сохранив примеры вёрстки.
- Функции: переключатель сравнения вариантов и доступный увеличенный просмотр галереи.

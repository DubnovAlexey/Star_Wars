## English

A static Star Wars layout study in HTML and CSS, preceding the React version ([star-wars-ts-routing](https://github.com/DubnovAlexey/star-wars-ts-routing)): the opening crawl of *A New Hope*, a hero photo and a gallery of friends, laid out three ways — a table, Flexbox and a centred Flexbox variant.

**Live demo:** https://dubnovalexey.github.io/Star_Wars/

### Try it

Open src/index.html, src/index_flex.html and src/centerFlex.html to compare the same composition in three layouts. Resize the window and inspect the hero image and dream-team gallery.

### What is inside

- `src/index.html` — the main page; `src/index_flex.html` and `src/centerFlex.html` — the same content with Flexbox layouts.
- A starry background and Star Wars styling in plain CSS.
- `starsWars.txt` — the source text of the opening crawl.

### Tech stack

HTML5 · CSS3 (Flexbox) · GitHub Pages

### Run locally

Open `index.html` (or `src/index.html`) in a browser.

### Demo scope

This is a static layout study. The navigation labels and “Send me email” are decorative placeholders; there is no API, message sending or interactive hero routing.

### Further development

Proposals below are planned work, not existing features.

- Visual: align spacing and mobile typography across the three layouts.
- Engineering: give the navigation real links and visible keyboard focus; consolidate repeated style rules while preserving the layout examples.
- Features: add a layout comparison switch and an accessible enlarged view of the gallery.

## Français

**Star Wars (HTML et CSS)**

Une étude statique de mise en page sur « La Guerre des étoiles » en HTML et CSS, antérieure à la version React ([star-wars-ts-routing](https://github.com/DubnovAlexey/star-wars-ts-routing)). On y trouve le générique d'ouverture d'« Un nouvel espoir », la photo du héros et une galerie d'amis, mis en page de trois façons : en tableau, en Flexbox et en Flexbox centré.

**Démo :** https://dubnovalexey.github.io/Star_Wars/

### À essayer

Ouvrez src/index.html, src/index_flex.html et src/centerFlex.html : c'est une même composition en trois variantes de mise en page. Changez la largeur de la fenêtre et comparez le portrait du héros avec la galerie de l'équipe.

### Ce qu'il y a dedans

- `src/index.html` — la page principale ; `src/index_flex.html` et `src/centerFlex.html` — le même contenu en Flexbox.
- Fond étoilé et habillage façon « Guerre des étoiles » en CSS pur.
- `starsWars.txt` — le texte d'origine du générique.

### Technologies

HTML5 · CSS3 (Flexbox) · GitHub Pages

### Lancer le projet

Ouvrez `index.html` (ou `src/index.html`) dans le navigateur.

### Limites de la démo

C'est une étude statique de mise en page. Les intitulés du menu et « Send me email » sont décoratifs : il n'y a ici ni chargement d'API, ni envoi de messages, ni routes interactives des héros.

Ce qui suit sont des propositions, pas des fonctions déjà réalisées.
